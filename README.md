# Orbit research group website

Static site sources for the Orbit group. Content lives under `docs/`; the
engineering platform team keeps operational notes under `ops/`.

## Layout

- `docs/team/index.md` — people and selected work
- `ops/debt-register.md` — curated engineering debt register
- `src/orbit/` — solver sources
- `tools/` — developer tooling
- `vendor/`, `third_party/` — external code, not maintained in this repository
